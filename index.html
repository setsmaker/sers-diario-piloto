Sobre este piloto

Los registros se almacenan en este navegador, en este dispositivo. No se sincronizan entre móviles. Exporta copias periódicamente: borrar los datos del navegador puede hacer que se pierdan.

La transcripción utiliza el reconocimiento de voz del navegador cuando está disponible. Puede necesitar Internet. Si no aparece, utiliza el micrófono del teclado.
