Los inspectores consultan las obras. El administrador autorizado puede editarlas desde el apartado siguiente.

Administrar obras en GitHub

Solo para el administrador de la cuenta GitHub setsmaker. Las modificaciones se publican en el catálogo compartido.

La primera vez, crea en GitHub un token de acceso específico con permiso de Contents: Read and write únicamente para setsmaker/sers-diario-piloto. Utiliza una caducidad corta. Crear token en GitHub ↗

El token se utiliza directamente con api.github.com y no se guarda en el móvil, ni se sube al catálogo. No lo compartas por chat.

Información y almacenamiento

Fotografías, notas, visitas y borradores se guardan en este dispositivo, no se sincronizan entre móviles. El catálogo común de obras se consulta desde GitHub. Exporta copias periódicamente: borrar los datos del navegador puede hacer que se pierdan.

La transcripción utiliza el reconocimiento de voz del navegador cuando está disponible. Puede necesitar Internet. Si no aparece, utiliza el micrófono del teclado.
